# 🛍️ Customer Shopping Behavior — Data Analytics Project

> End-to-end data analytics project built with **Python**, **SQL**, and **Power BI** on a retail customer behavior dataset.


---

## 📌 Project Overview

A retail company wants to better understand its customers' shopping behavior to improve marketing and sales strategy.

This project covers the full analytics workflow:
- **Python** — Data cleaning and exploratory data analysis (EDA)
- **SQL** — Answering business questions through queries
- **Power BI** — Interactive dashboard for stakeholders

---

## 🗂️ Dataset

The dataset contains **3,900 customer transactions** with information on age, gender, product category, purchase amount, season, discounts, subscriptions, and more.


---

## 🔍 Key Insights

- 🏆 **Clothing** is the top revenue-generating category
- 📅 **Fall and Spring** seasons show the highest purchase volumes
- 💳 Customers using **promo codes** spend more on average
- 🔄 **Subscribed customers** shop more frequently
